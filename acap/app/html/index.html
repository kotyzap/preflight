Preflight

1.0.0

Scans this camera's network and tells you which cameras survive an AXIS OS upgrade — before you start it. Read-only: it lists applications and reads settings, and writes nothing to any device.

Camera credentials

Stored on this camera only, and never sent anywhere except to the cameras being checked. Add as many sets as your fleet uses — each camera is tried against them in order. Cameras that accept none are reported as unverified, never as safe.

One per line. This camera's own /24 is always scanned; anything else has to be listed here.

Every rule this app checks is published with its source at preflight.4xs.dev. The exact list of endpoints it requests is shown by status — all GET, all read-only. It also sends one ONVIF discovery probe, the same one every VMS on the network sends, which asks devices to state their model and changes nothing.
