Preflight

Scans this camera's network and tells you which cameras survive an AXIS OS upgrade — before you start it. Read-only: it lists applications and reads settings, and writes nothing to any device.

Credentials for the other cameras

Stored on this camera only, and never sent anywhere except to the cameras being checked. Cameras that refuse these credentials are reported as unverified, never as safe.

Every rule this app checks is published with its source at preflight.4xs.dev. The exact list of endpoints it requests is shown by status — all GET, all read-only.
